# 🟡 TerraVaga

Plataforma de vagas especializada no setor de terraplanagem, pavimentação e infraestrutura.

## 🚧 Status
Em desenvolvimento ativo.

## 🛠 Stack
- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Supabase (em breve)

## 💡 Sobre o projeto
O TerraVaga conecta profissionais especializados (operadores de máquinas, topógrafos, engenheiros) com empresas do setor de movimento de terra — um nicho sem plataforma dedicada no Brasil.

## 🚀 Rodando localmente
```bash
npm install
npm run dev
```
Acesse http://localhost:3000
